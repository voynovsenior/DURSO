# DURSO Website

Static bilingual EN/RU landing page for the DURSO community project.

## Files
- `index.html` — page structure
- `styles.css` — responsive cosmic visual design
- `app.js` — language switch, mobile navigation and starfield animation

## Publish with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, select **GitHub Actions** as the source.
3. The included workflow deploys the repository root automatically on pushes to `main`.

The website does not contain a token contract address or promise financial returns. Update external social links only after verifying the official account.
